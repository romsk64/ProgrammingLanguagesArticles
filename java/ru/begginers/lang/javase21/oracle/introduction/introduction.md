# Введение в Java.

Java — это компилируемый объектно-ориентированный язык программирования. Язык был создан для облегчения разработки программ и портирования их на различные устройства.<br>
Он работает на своей виртуальной машине (JVM — Java Virtual Machine), так что вам не нужно вручную портировать вашу программу на различные платформы (как пк, смартфон и тд.). Но для запуска нужна виртуальная машина, так что нужно скачать сначала ее. Если же на вашу платформу Jav'ы нет, программу запустить будет нельзя.

Что же значит "объектно-ориентированный"? Это значит что в основе языка стоят классы.<br>
Классы — это как шаблон для объектов. То есть если вам нужно несколько машин, можно создать один класс "Машина" и потом создавать одинаковые объекты этого класса (много машин).

## Про компиляцию
Ну а что значит компилируемый? Тут все очень просто — он использует компилятор для запуска своих программ. Компиляция — это перевод программы сразу в машинный код или в байт-код.<br>
Машинный код используется для нативного запуска программы (например, если у вас Windows, то компилятор переводит программу в формат .exe, и вы можете запустить программу без стороннего софта).<br>
Но Java переводит программы в байт-код для своей JVM. И без JVM (как я говорил выше) запустить программу нельзя.

В большинстве исполнений Java, в том числе и Oracle OpenJDK за компиляцию программы овечает программа javac.exe. Если папка с компилятором находится в PATH, вы можете вызвать компилятор, просто введя `javac` в командную строку. Но если же он не стоит в PATH (но я рекомендую все же поставить папку с компилятором в PATH, так как это гораздо облегчит вашу работу), то введите отностельный путь до javac.exe от выбранной папки (пишется слева от ">").

Чтобы скомпилировать программу нужно вписать `javac` (или путь до него, далее повторять это я не буду) и после пробела ввести путь до файла, например: `javac MyProgram.java`. После этого, в выбранной папке создастся файл `MyProgram.class` (ну или с другим именем, если имя исходного java файла было другим).

Для запуска уже понадобится другой файл: `java.exe`. Он также есть в большинстве исполнений Java, и в исполнении от Oracle он тоже есть. Для запуска вам нужно ввести `java MyProgram`. Как вы видите, писать расширение более не нужно, так как java.exe принимает только название программы.
