# Введение в Java.

Java — это объектно-ориентированный язык программирования. Язык был создан для облегчения разработки программ и портирования их на различные устройства.<br>
Он работает на своей виртуальной машине (JVM — Java Virtual Machine), так что вам не нужно вручную портировать вашу программу на различные платформы (как пк, смартфон и тд.). Но для запуска нужна виртуальная машина, так что нужно скачать сначала ее. Если же на вашу платформу Jav'ы нет, программу запустить будет нельзя.

Что же значит "объектно-ориентированный"? Это значит что в основе языка стоят классы.<br>
Классы — это как шаблон для объектов. То есть если вам нужно несколько машин, можно создать один класс "Машина" и потом создавать одинаковые объекты этого класса (много машин).
