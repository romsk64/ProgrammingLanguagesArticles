# Packages
Packages, или же пакеты позволяют структурировать Java программы. Пакеты — это те же самые папки, так что несколько пакетов с одинаковыми названиями в одном пакете или несколько java-файлов с одинаковыми названиями в одном пакете недопустимы. И да, вы можете создавать пакеты в пакетах.

Для обозначения принадлежности файла какому-либо пакету в Java используется ключевое слово `package`. Пакеты относительны папке, в которой расположен ваш проект. То есть если проект у вас расположен в `src/`, а какой-то файл вашего проекта в `src/mathoperations/standart/`, то в этом файле вы должны написать на самом верху:
```Java
package mathoperations.standart;
```
Теперь, если вы скомпилируете файл, и он создастся в той же папке (`src/mathoperations/standart/`), вы сможете корректно его запустить. Например, если вы создадите файл `Power.java` и скомпилируете его, для запуска нужно просто ввести `java mathoperations.standart.Power`.<br>
То есть команда запуска: `java {пакет, в котором содержится файл}.{имя скомпилированного файла}`
