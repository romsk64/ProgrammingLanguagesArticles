# Первая программма
Давайте напишем нашу первую программу на Java! Для начала нужно создать файл `Program.java`.
```Java
public class Program {
    public static void main(String[] args) {
        System.out.print("Hello World!");
    }
}
```
### Что же делает эта программа?
Как вы видите на первой строке мы создаем класс с названием "Program". И да, классы должны всегда соответствовать названию файла, в котором этот класс содержится.

> Рекомендуется писать классы (и названия файлов соответственно) с большой буквы, так как и вам, и большинству других разработчиков будет сразу понятно что здесь класс, а что здесь не класс. Также если в названии класса несколько слов, то рекомендуется писать каждое последующее слово без нижних подчеркиваний, а сразу писать следующее слово с большой буквы, то есть не так: `My_Program`, а так: `MyProgram`. **НО ЭТО НЕ ОБЯЗАТЕЛЬНО *(просто рекомендация)***.

Далее идут фигурные скобки, в них пишется то, что находится в этом классе. Вообще фигурные скобки в самом языке обозначают какий-нибудь блок кода.

На третьей строке идет создание метода. Метод — это определенный блок кода, котой может исполнятся, если его вызвать. Также в других языках есть функции, это буквально точь в точь как метод. Но они отличаются тем, что метод находится только в классах, а функция — вне класса. Но так как Java — целиком объектно-ориентированный язык (и за классами почти ничего нет) понятие функции в нем отсутствует.

Метод main() — главный метод в программе, он исполняется автоматически, в отличии от других методов, которые нужно вызывать по имени. Что за "String[] args" в скобках метода? Это называется аргументы. При вызове программы из командной строки вы можете передать определенные аргументы в массив "args" (про массивы поговорим позже).

А что же такое эти "public", "static"? Это модификаторы и о них мы поговорим чуть позже.

Далее, в фигурных скобках уже метода main(), содержится основной блок кода. И основной код содержит всего лишь одну строку: `System.out.print("Hello World!");`. Эта строка содержит метод print(), в его аргументы мы передаем строку со значением "Hello World!". И уже этот метод выводит в командную строку (терминал или откуда вы там запускаете программу) переданное в него значение "Hello World!".

Ну и следующие две строки просто закрывают открытые фигурные скобки, так как открытыми их оставлять нельзя, так как компилятор будет ругаться.
