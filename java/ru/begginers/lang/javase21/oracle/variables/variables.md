# Переменные и типы данных
> Переменные — это ячейки памяти с определенной заложенной в них информацией. У них есть свой определенный тип данных. Переменные обычно хранятся в оперативной памяти.

Так как Java — статически-типизированный язык программирования, переменные не могут менять свой тип данных, то есть если определенная переменная содержит целое число, она не сможет поменять значение на строку.<br>
Но существуют и динамически-типизированные языки программирования (Python, JavaScript (не путать с Java, он с ней никак не связан) и др.), и в них вполне можно сменить тип данных переменной.

## Объявление (инициализация) переменной
Для объявления переменной нужно сначала указать ее тип. Возьмем, к примеру, тип данных `int (Integer)`. Этот тип данных обозначает целое число.

В Java переменная объявляется так:
```Java
int x = 10;
```
То есть, сначала идет тип данных, далее название переменной, в примере это `x`, после идет знак равно, еще его называют *оператором присваивания*, а уже в правой части содержится значение, которое мы хотим присвоить.<br>
Это инициализация переменной с присваиванием ей значение одновременно.

Но иногда нужно сначала проинициализировать переменную, а уже потом, в процессе работы программы, присвоить ей значение.

Это делается так:
```Java
int x;
```
После инициализации переменной и с присваиванием ей значения, и без него, его можно поменять.
```Java
x = 15;
```
То есть тип указывать не нужно, нужно сразу писать название переменной, а после — ее новое значение.

Но все-таки зачем нужны переменные? С ними можно делать очень много разных вещей, например выводить на экран:
```Java
int num = 15;
System.out.print(num);
```
Или производить математические операции (но про это подробнее в следующей статье)
```Java
int num1 = 15;
int num2 = 20;
int result = num1 + num2;
System.out.print(result);
```


### Типы данных
Существуют такие типы данных, как:
1. int (Integer) — целое число, один из самых распространенных типов данных в программировании. Занимает 4 байта и имеет значение от -2147483648 до 2147483647.
2. short — целое число. Занимает 2 байта.
3. byte — целое число. Занимает 1 байт.
4. long — целое число.
5. double — число с плавающей точкой (десятичное дробное число). В качестве запятой используется точка: `3.14`. Занимает (забыл) байт
6. float — число с плавающей точкой.
7. boolean — логический тип данных. Имеет только 2 значения `true` или `false` (1 или 0).
8. char — символ, но ему можно присвоить число при инициализации. Если это сделать, то переменная конвертирует данное число в символ по таблице ASCII.
9. String — строка, является классом, так что поговорим о ней попозже.
