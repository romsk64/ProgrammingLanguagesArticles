# Тип данных **float**
> Тип данных *float* обозначает дробное число, то есть число с плавающей точкой

То есть переменная `x = 0.5` будет содержать дробное число 0.5.

У типа данных *float* нет точного максимального или минимального значения, так как чисел после запятой может быть бесконечное количество и каждая цифра занимает байт оперативной памяти. Также как и у типа [*int*](./int.md), *float* может потреблять всю оперативную память, выделенную на программу.
