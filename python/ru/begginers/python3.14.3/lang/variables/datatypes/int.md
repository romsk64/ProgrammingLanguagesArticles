# Тип данных **int**
> Тип данных *int* обозначает целое число.

То есть переменная `x = 5` будет содержать целое число 5.

У типа *int* нет максимального и минимального значения, как в других языках или в том же Python 2 (в нем было 2 типа – *int* и *long*, первый был ограничен, второй это по сути нынешний *int*), все зависит от количества выделенной на программу оперативной памяти, он может потреблять ее сколько угодно.
