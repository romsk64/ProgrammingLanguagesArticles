# Переменные
> Переменные — это ячейка памяти, которая содержит определенные данные. У каждой переменной есть свой тип данных: строка, число или др. В некоторых языках менять тип переменной нельзя (в статически-типизированных языках), но в Python — можно (так как это динамически-типизированный язык)

В Python переменная объявляется так: <br>
`{имя переменной} = {значение переменной}`.<br>
Тип данных определяется сам.

Для начала давайте познакомимся с переменными типа [int](int/int.md) (число)
