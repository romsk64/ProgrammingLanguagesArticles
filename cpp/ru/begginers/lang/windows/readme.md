# Курс для новичков по C++
У C++ существуют стандарты. Это по сути версии C++, и в каждом из стандартов есть свои улучшения и доработки. Так что я поделил этот курс по различным стандартам, но в большинстве вещей все стандарты будут друг с другом схожи. Также существуют диалекты языка – те же стандарты, но с некоторыми улучшениями уже от разработчиков диалекта.
