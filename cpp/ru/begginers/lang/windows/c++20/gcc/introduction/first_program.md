# Первая программа на C++
Пришло время написать первую C++ программу. По ходу написания я буду объяснять вам что за что отвечает и что все это обозначает.

Программисты еще очень давно в качестве первой программы пишут программу, которая выводит в консоль фразу "Hello World!". И мы такую напишем.

Для начала нужно создать файл с названием, допустим, *helloworld.cpp* (.cpp – это расширение для C++ файлов).

``` C++
#include <iostream>
```
Это первая строка нашей программы. `#include` – это директива препроцессора, то есть она выполняется еще до компиляции программы, и эта директива вставляет в нашу программу заголовочный файл (про них позже) `<iostream>`, который отвечает за ввод и вывод в консоль различных данных.

``` C++
using namespace std;
```
Что это такое? `namespace` – пространство имен – это блок различных функций, переменных, классов и т.д. (про все это позже). `using` – это слово для использования пространства имен. А `std` – само название пространства. Можно обойтись и без данной строчки, но в таком случае придется указывать название пространства имен каждый раз при вызове функции оттуда.

``` C++
int main() {

}
```
Это главная функция программы (и пока что единственная) – main(). В теле функции (в фигурных скобках) размещается основной код программы.

``` C++
    cout << "Hello World!" << endl;
```
Это основной код программы и он пишется в теле функции main(). `cout` – расшифровывается как *console out* – выводит текст. После идет сам текст, а в конце `endl`, то есть *end line*, то есть это перевод на следующую строку.

``` C++
    return 0;
```
Это тоже находится в теле функции main(). Это оператор возврата значения. Но если это функция main(), то тогда если возвращается 0, то это дает сигнал компьютеру, что программа завершилась успешно, если же любое другое число, кроме 0, это дает сигнал компьютеру, что программа завершилась с ошибкой.

В современных версиях компиляторов писать `return 0;` необязательно, ведь в конце программы компилятор может сам подставить `return 0;`, но все же так еще делают многие люди.

И вот итоговый результат:
``` C++
#include <iostream>
using namespace std;

int main() {
    cout << "Hello World!" << endl;

    return 0;
}
```
Как вы видите, можно спокойно добавлять пустые строки, лишние пробелы и табуляцию для большей читабельности кода, ведь все это все равно удаляется при компиляции.

Также существуют комментарии для того, чтобы обозначать какие-то куски кода. Комментарии также удаляются при компиляции. Они бывают однострочные и многострочные:
``` C++
// однострочный комментарий

/*
многострочный
комментарий
*/

// а также многострочные комментарии можно использовать так:
cout /* вывод текста */ << "Text" /* сам текст */ << endl;
```
Однострочные комментарии, как вы уже поняли начинаются с **//**, а многострочные – начинаются с **/\***, а оканчиваются на **\*/** (и с помощью многострочных комментариев можно заккоментировать какую-то часть кода, находящуюся посередине строки).

То есть нашу программу можно улучшить еще и таким образом:
``` C++
#include <iostream> // включение биюлиотеки с вводом-выводом
using namespace std;

// главная часть
int main() {
    cout << "Hello World!" << endl; // вывод "Hello World!" в консоль

    return 0; // выход из программы
}
```

И да, теперь нужно запустить программу. А запустить ее можно только после компиляции. Для начала вам нужно выбрать папку, где вы будете хотите видеть исполняемый файл и где лежит ваш файл с кодом. После чего нужно скопировать путь этой папки и в консоли ввести команду `cd путь\к\папке`. Теперь вы должны скомпилировать файл. Для компиляции C++ кода используется компилятор g++ (g++.exe). Если вы добавили папку bin в переменные среды, как было сказано во введении, нужно вписать `g++ название_вашего_файла.cpp`, ну или же если вы назвали файл *helloworld.cpp*, то нужно ввести `g++ helloworld.cpp`. Также можно и не входить в директорию с вашим файлом, а ввести полный (или относительный от начальной папки) путь до файла (но в таком случае выходной файл будет в изначально выбранной директории). В итоге в выбранной директории появится файл *a.exe*. Чтобы его запустить, нужно ввести команду `.\a.exe` или `.\a` (.exe можно опустить, от этого ничего не изменится, так что дальше по всему курсу я буду всегда его опускать). Также в современных версиях Windows обратную косую черту (**\\**) можно заменить на обычную (**/**), то есть `./a.exe` или `./a`. Если вы спросите зачем нужна точка с косой чертой перед *a.exe*, то это обозначение текущей директории. Если написать просто `a.exe` или `a`, то ничего не получится, так как без указания директории можно вписывать только программы, находящиеся в Path.

И да, после запуска в консоли выведется такой текст:
```
Hello World!
```
Если запустить программу из проводника двойным кликом, то программа сразу же закроется, так как кроме вывода текста ничего не происходит, программа сразу же закрывается вместе с открывшейся консолью.

Также если вам не нравится название программы (a.exe) и вы не хотите ее переименовывать каждый раз после компиляции, то существует параметр `-o` (параметр – это дополнительное свойство компиляции (если мы говорим про компилятор)). После него вписывается название скомпилированного файла. То есть если вы к примеру хотите скомпилировать файл *helloworld.cpp* в исполняемый файл *helloworld.exe*, то нужно лишь вписать команду `g++ helloworld.cpp -o helloworld.exe` (.exe можно опустить: `g++ helloworld.cpp -o helloworld`). И запускать уже не `./a`, а `./helloworld`. А еще обычно параметры пишутся уже после файла с кодом.

И еще расскажу про параметр `-std`. Он задает стандарт C++. Стандарт пишется после равно, который пишется после -std. То есть если вы хотите скомпилировать программу под стандарт, например, C++23, то команда будет такая: `g++ helloworld.cpp -std=c++23 -o helloworld` (параметры можно указывать в любом порядке, от изменения места ничего не изменится). По умолчанию, без указания стандарта, используется gnu++20 (это диалект C++20). Различий между C++20 и gnu++20 немного, а вообще на начальном этапе, на котором находитесь вы, от стандарта к стандарту ничего не меняется, так что вы можете на сотню уроков вперед вообще забыть про этот параметр.
